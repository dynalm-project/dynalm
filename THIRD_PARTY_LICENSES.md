## ggml v0.27.0

Compiled into `dynalm` and `dynacorec` when built with a GPU backend (`-DENABLE_METAL`,
`-DENABLE_VULKAN`, `-DENABLE_CUDA`; docs/gpu.md) or with ggml's CPU kernels (`-DENABLE_GGML_CPU`,
ON by default where ggml's CPU backend builds: CMake >= 3.28, not MSVC on ARM64). Source:
https://github.com/ggml-org/ggml, commit

`a05c9922613c6a2230dbb1d0de679519ecafb4f0` (tag v0.27.0), pinned in `cmake/Ggml.cmake`.
Builds with `-DENABLE_GGML_CPU=OFF` and no GPU backend contain no ggml code.
